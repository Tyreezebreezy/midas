## Known limitations

- **Silent reinstall directly over an existing installation can hang.** Reconfirmed this session: running the installer with `/S` while a previous MIDAS installation is present can wait on a confirmation dialog that silent mode does not suppress. A normal interactive install, or installing after a full uninstall, both work correctly. Not fixed in this release for the same reason Phase 7 documented - it needs custom NSIS scripting beyond Tauri's default template.
- **The CSV import wizard's preview step shows unformatted dates.** The human-readable date formatting added before this release covers Overview, Transactions, Reports, Bills, Goals, and Settings, but the import wizard's own staging-preview table (before you click "Import") still shows raw `YYYY-MM-DD` values - a gap in that pass's own sweep, not a functional defect. Cosmetic only; every other user-facing date in the app is formatted.
- Backups are manual, not scheduled or automatic - MIDAS doesn't run in the background.
- The database file is not encrypted at rest - relies on OS-level disk/account security.
- CSV export is one-way, for reading elsewhere - not intended to round-trip back through the importer.
- No multi-device sync - each installation has its own independent database unless manually backed up and restored between them.
- Windows is the only platform built and tested.
- No desktop shortcut is created by default (Start Menu only) - standard NSIS default, not a defect.
