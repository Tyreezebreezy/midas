## Test results

- **Regression**: `cargo fmt --check`, `cargo check --locked`, `cargo test --locked` (174/174 passing), `cargo clippy --locked --all-targets -- -D warnings` - all clean. Full frontend check (`prettier`, `tsc`, `node --test`, `vite build`) - clean.
- **Fresh install**: built the NSIS installer, moved the pre-existing dev-mode database aside so the app data directory (see README's "Your data" section for the exact path) was genuinely empty, silently installed, launched the _installed_ `midas.exe` (not `tauri dev`), confirmed a brand-new `midas.sqlite3` was created and all 7 migrations applied cleanly (every command that touches later-migration tables/columns worked without a SQL error).
- **Installed-app functional smoke test**: account creation, manual transaction entry, CSV import (including exact-duplicate detection on a re-import), recurring detection and confirmation, a budget's actual spending, a pay schedule and its cycle summary, Safe to Spend, a savings goal, net worth, Overview, Reports (category breakdown and trend), and backup/export/restore - all exercised through the real installed app's IPC, every returned number hand-verified against the seeded data (e.g. Safe to Spend's $7,309.41 = $7,329.40 eligible cash − $19.99 in confirmed obligations, computed independently and matched exactly).
- **Persistence/relaunch**: closed the installed app completely, reopened it, re-queried every seeded value (account balance, transaction count, budget actual, goal status, confirmed recurring count, pay schedule, net worth) - every one matched exactly.
- **Disaster recovery**: backed up the seeded data, saved the backup _outside_ the app's data directory, closed the app, removed the live database entirely (simulating data loss), relaunched onto a genuinely empty database (confirmed 0 accounts), restored from the externally-preserved backup, and re-verified every value (balance, transaction count, budget, goal, recurring series, pay schedule) against what was recorded before the simulated disaster - all matched exactly.
- **Larger backup test**: seeded 3,000 additional transactions through the real installed app's IPC (not a Rust-only benchmark) and measured the actual base64-over-IPC round trip: backup 45 ms, preview-validate 29 ms, restore 36 ms, for a ~0.72 MB backup covering 3,008 total transactions. Measured, not speculated.

Verified uninstall removes the application files, shortcut, and registry entry (NSIS's normal asynchronous self-delete takes a few seconds after the visible process exits - confirmed by re-checking, not assumed from the first look). **Verified the database file's MD5 checksum is byte-for-byte identical before and after uninstall - uninstalling MIDAS does not touch user financial data.** Verified a clean reinstall after full uninstall works correctly. ## Known limitations

- **Silent reinstall directly over an existing installation hangs.** Running the NSIS installer with `/S` while a previous MIDAS installation is already present does not complete - it waits on a confirmation `MessageBox` (NSIS's default "already installed" check) that silent mode does not suppress. This only affects _scripted/silent_ reinstall specifically: a normal interactive install shows the same dialog to a real user, who can simply click through it, and installing after a full uninstall (also tested) works correctly. Not fixed in this release - it would need custom NSIS scripting (an `.onInit` silent-mode check) beyond Tauri's default template, which is more than a "defect required for release readiness" justifies on its own; recorded here as a real, verified limitation rather than papered over.
- Backups are manual, not scheduled or automatic - MIDAS doesn't run in the background.
- The database file is not encrypted at rest - relies on OS-level disk/account security.
- CSV export is one-way, for reading elsewhere - not intended to round-trip back through the importer.
- No multi-device sync - each installation has its own independent database unless manually backed up and restored between them.
- Windows is the only platform built and tested.
- No desktop shortcut is created by default (Start Menu only) - standard NSIS default, not a defect.
