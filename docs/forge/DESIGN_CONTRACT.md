# MIDAS Design Contract

## Existing direction

Preserve the implemented private Windows finance application; this pilot does not redesign it.

- Deep money-green application background
- Gold as restrained signature emphasis
- Warm, highly legible financial text
- Swiss-inspired hierarchy and bento grouping
- Tabular alignment and explicit text for financial meaning
- System, Light, and Dark themes
- Desktop-first layouts tested at 1280x800 and 1024x640

## Interaction rules

Safe to Spend remains the primary overview value. Gold guides attention but never replaces semantic status. Positive/negative, review, warning, and destructive states do not rely on color alone. Dense transaction/import surfaces remain keyboard and mouse scannable.

## Boundaries

No redesign, visual framework, chart library, new palette, or dashboard restructuring is introduced. The active application implementation and product context remain authoritative.
