Batch 2 / Import Engine v2 (`specs/phase-009-import-engine-v2/spec.md`) is complete: the CSV importer now saves/recognizes/reuses import profiles (conservative header-based recognition, never a weak-signal guess), a four-outcome deterministic matcher (New/ExactDuplicate/StrongMatch/PossibleMatch - only a byte-identical or external-ID match ever auto-skips without asking), payee linkage by exact name match, an external-transaction-ID mapping column, migration 0009 (`imports.excluded_count`/`undone_at`/`undone_removed_count`, `import_profiles.is_archived`), a first-class Import History view, and a safe partial Undo (removes only transactions untouched since import).
